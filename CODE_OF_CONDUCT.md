# Code of Conduct

This project follows the [Qiskit Code of Conduct](https://qisk.it/coc).

In short: be respectful, be welcoming, and assume good faith. Harassment and
discrimination of any kind are not tolerated in issues, pull requests, or
discussions about this project.

To report a problem, open an issue or contact the maintainer,
[@Lokesh-2025](https://github.com/Lokesh-2025), on GitHub. For anything you
would rather not post publicly, say so in a short message and a private channel
will be arranged.
